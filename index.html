使用流程
1. 工程部在「设置」中选择当前账期 → 2. 导入 CSV 抄表数据（可含「月份」列，一次导入多个月） → 3. 导出 meter-data.json 并部署 → 4. 商户扫码输入商铺号核对最新账期并手写签字（可查看历史账期） → 5. 商户导出签字文件发给工程部 → 6. 工程部导入签字文件按账期汇总 → 7. 内部三方（抄表员/领导/客服代表）按账期签署 → 8. 按账期+楼层生成 PDF 签字确认表。
数据说明
抄表与签字均以账期（月）为单位管理：各账期数据、商户签字、内部签字相互独立，切换账期即可浏览历史记录。所有数据保存在各设备浏览器本地（localStorage），不上传服务器；多设备通过「签字文件」手动合并。同一商铺号有多只水表时，商户一次签字即确认该商铺全部水表。

使用说明

一、工程部：按账期导入抄表数据
进入「工程部入口」（默认密码 123456，可在设置中修改），先在「设置」中选择当前账期，再到「数据管理」导入 CSV 文件。表头：序号, 月份, 商铺号, 商铺名称, 水表井编号, 水表规格(DN), 上月读数(m³), 上月用量(吨), 本月读数(m³), 用量(吨), 单价(元), 金额(元)。「序号」「客户签字」列自动忽略；楼层按铺位号自动识别（如 L8-001 → 8F、B1-301 → B1），也可增加「楼层」列指定；「月份」列（如 2026-09）可将数据导入指定账期，未填时归入当前账期。CSV 中已填写的用量、金额将直接采用，未填写时自动按「本月读数−上月读数」「用量×单价」计算。顶部账期选择器可切换浏览各月历史数据。
二、工程部：发布数据文件
点击「导出数据文件」得到 meter-data.json（包含全部账期），与页面一起部署到 GitHub Pages。商户扫码后页面会自动加载该文件。「导入数据文件」同时支持 CSV 与 meter-data.json（自动识别），可用于恢复备份的数据。
三、商户：扫码核对并签字
商户扫码打开页面 → 输入商铺号（也可输商铺名称）→ 核对最新账期该商铺全部水表的读数、用量、单价、金额 → 手写签字确认 → 点击「导出签字文件」将文件发给工程部。页面上方可查看该商铺历史账期记录（只读）。
四、工程部：按账期汇总签字
切换到对应账期，在「签字汇总」中导入该账期各商户的签字文件，查看签字进度；再由抄表员、工程部领导、客服代表在「内部签字」中完成该账期签署。
五、工程部：按账期与楼层导出 PDF
在「PDF导出」中选择账期与楼层，生成横版 A4 签字确认表，含电子签字图像与内部三方签字栏。
